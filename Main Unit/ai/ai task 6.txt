Мне нужно, чтобы пользователь мог задавать имя для сохраненного измерения/серии измерений, либо при сохранении, либо далее, при просмотре ранее сохраненном измерении/серии измерений. Имя должно быть не более 40 символов. Когда пользователь редактирует имя он редактирует его посимвольно, поворотом энкодера листает символы в текущей позиции курора, нажатием кнопки энкодера курсор переходит к след символу. Я предпологаю, что сохранять имя записи нужно в  новом поле "name" в StoredMeasuredResult и StoredMeasuredSeries.

Когда пользователь вводит символы, то ему должно подсказыватся продолжение строки из массива FilmCamerasList. Т.е., например, он ввел первый символ "N", и ему сразу должно показать серыми буквами "Nikon 28Ti". Т.е. первая буква, которую он ввел, "N", белая а дальше "ikon 28Ti" - серыми. Дальше он нажал на кнопку энкодера, и перешел к редактированию след буквы. След. буква уже должна подхватиться из строки-подсказки, т.е. "i". Но, допустим, пользователь хочет ввести не "Nikon 28Ti", а "Norita 1". Т.е. он меняет поворотом энкодера вторую букву с "i" на "o", ему сразу должно предложить подсказку "Norita 66" и т.д. Он клацает на кнопку энкодера, соглашаясь по одной букве с подсказкой "Norita", а потом он вместо "66" вводит поворотом энкодера "1". Т.е., мы предлагаем пользователю ввод, он может соглашаться с подсказкой, но не мешаем ему вводить свой текст.  Пользователь должен иметь возможность вводить пробел, английские большие/маленькие буквы/цифры, а также символы "-", "(", ")", "+", "<", ">", "{", "}", "[", "]", "/", "#", ".", "*", "&". Строка с именем должна быть вся видна на экране, не прокручиваться, понимаю, что тогда она будет отображаться на 2 строчках, ну ничего. В под строками с именем нужно разместить область для вывода сообщений, например, что введенное имя уже существует. Под этой областью нужно разместить меню с пунктами "Ok", "Cancel", "Delete Mode", "Back To Edit".

"Ok" сохраняет имя, "Cancel" - отменяет. При выборе "Delete Mode" фокус снова переходит на область ввода имени, но теперь курсор меняется на "<" и пользователь нажатием кнопки энкодера стирает один символ слева от курсора и курсор перемещается на один символ влево. В режиме "Delete Mode" пользователь также может перемещать курсор зажатием кнопки и поворотом энкодера, как будет описано ниже. Нажатием на "Back To Edit" курсор просто переходит назад на область редактирования.

Если пользователь не ввел имя и нажал "Ok", то нужно показать в области сообщений сообщение "Name is empty". Если введенное имя уже существует, то нужно показать "Name already exists".

Когда пользователь выбирает "Yes" при запросе на сохранение после измерения нужно показывать страницу, на которой пользователь может выбрать между старым именем и заданием нового имени: например "Save as '0002'" и "Save as...". По нажатии на "Save as '0002'" в массив name нужно записать название вида "0002", т.е. как старый вывод имени, где просто форматировался "recordNumber" и сохранить запись с этим именем. При выборе записи "Save as..." нужно показывать новую страницу ввода имени. 

По навигации по строке во время редактирования: 
1. Удержание кнопки + поворот энкодера — перемещение курсора влево/вправо.

2. Удержание без поворота (зажал на более чем 700 мс) — переход в меню внизу страницы. Меню было описано выше.


 Нужно также реализовать миграцию со старых записей, которые уже есть на устройстве. При миграции нужно в имя (name) позаписывать форматированные recordNumber и сохранить заново все записи. Старый механизм форматирования имени по recordNumber уже не будет использоваться, поэтому нужно позаполнять name.

Серийный API пока не трогай.

Страницу выбора имени («Save as '0002'» / «Save as...») показывай для "Yes", "Overwrite Oldest", "Overwrite Newest", "Sel, rec. to overwrite". При выборе "Yes", "Overwrite Oldest", "Overwrite Newest" нужно показывать страницу редактирования имени без предзаполнения, а в случае "Sel, rec. to overwrite" нужно предзаполнить имя именем той записи, которую выбрал пользователь.

В списках Select record нужно отображать новые имена сразу на 2-х строках более мелким шрифтом, если имя не влазит на 1 строку при обрезании пробелов в хвосте.

Для переименования записи в меню "What's next" нужно добавить новый пункт "Rename record". При его выборе нужно открыть страницу ввода имени и предзаполнить имя текущим именем записи.

Старайся сделать новую страницу так, чтобы при обновлении какой-то части страницы, например курсора, не перерисовывалясь вся страница целиком и не было видно моргания текста или других элементов, которые не обновлялись.
