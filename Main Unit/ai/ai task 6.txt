Мне нужно, чтобы пользователь мог задавать имя для сохраненного измерения/серии измерений, либо при сохранении, либо далее, при просмотре ранее сохраненном измерении/серии измерений. Имя должно быть не более 40 символов. Когда пользователь редактирует имя он редактирует его посимвольно, поворотом энкодера листает символы в текущей позиции курсора, нажатием кнопки энкодера курсор переходит к след символу. Курсор в режиме ввода символов должен отображаться как подчеркивание. Курсор долже отображаться серым, если он не активен. Т.е. если мы в области меню, то курсор в области редактирования должен быть серым, и наоборот, если мы редактируем, то курсор внизу должен быть серым.

Когда пользователь вводит символы, то ему должно подсказыватся продолжение строки из массива FilmCamerasList. Т.е., например, он ввел первый символ "N", и ему сразу должно показать серыми буквами "Nikon 28Ti". Т.е. первая буква, которую он ввел, "N", белая а дальше "ikon 28Ti" - серыми. Дальше он нажал на кнопку энкодера, и перешел к редактированию след буквы. След. буква уже должна подхватиться из строки-подсказки, т.е. "i". Но, допустим, пользователь хочет ввести не "Nikon 28Ti", а "Norita 1". Т.е. он меняет поворотом энкодера вторую букву с "i" на "o", ему сразу должно предложить подсказку "Norita 66" и т.д. Он клацает на кнопку энкодера, соглашаясь по одной букве с подсказкой "Norita", а потом он вместо "66" вводит поворотом энкодера "1". Т.е., мы предлагаем пользователю ввод, он может соглашаться с подсказкой, но не мешаем ему вводить свой текст.  Пользователь должен иметь возможность вводить пробел, английские большие/маленькие буквы/цифры, а также символы "-", "(", ")", "+", "<", ">", "{", "}", "[", "]", "/", "#", ".", "*", "&".

Строка с именем должна быть вся видна на экране, она должна отображаться на экране в 2 строки по 20 символов в каждой, каждая из 2 строк должна быть по центру экрана. В под строками с именем нужно разместить область для вывода сообщений, например, что введенное имя уже существует. Под этой областью нужно разместить меню с пунктами "Ok", "Cancel", "Delete Mode [On/Off]". Пользователь может переместить курсор в область меню зажатием кнопки энкодера на более чем 700мс без поворота. Удержание кнопки + поворот энкодера — перемещение курсора влево/вправо на один символ. Курсор можно перемещать по всем символам строки, включая пробелы и символы, которые являются частью подсказки. Подсказка не чуствительна к регистру уже введенных символов.

Предложение подсказок должно работать с начала слова в любой позиции строки. Следующий поиск должен начинаться от конца последней подсказки. Например есть такая входная строка: 
"C n N    fniko    min        ocord      ". После расстановки подсказок она будет иметь такой вид: "CanoN 7  fniko    minolta Autocord      ". Символы, которые являются частью подсказки, должны отображаться серым, остальные символы названия - белым. Отображаемая на экране строка(введенные символы + символы, которые являются частью подсказки) должна пересчитываться при изменении строки пользователем (изменение символа, удаление символа)

В меню "Ok" сохраняет имя, "Cancel" - отменяет. При выборе "Delete Mode [Off]", надпись меняется на "Delete Mode [On]" и фокус переходит на область ввода имени, но теперь курсор меняется на вертикальную черту, похожую на символ "|". Она отображается между символами и пользователь поворотом энокодера влево/вправо стирает один символ слева/справа. При повороте влево - стирается символ слева, "|" переходит на один символ влево и все символы, которые были справа от "|" смещаются на одну позицию влево, самый последний (40-й) символ всей строки стает пробелом - " ". Пример: "Nicon F2                                ". Представим, что в этой строке "|" стоит между символами "c" и "o". При повороте влево символ "c" удаляется, а все что справа смещается влево на 1 символ и в результате строка будет иметь вид "Nion F2                                 ". "|" перемещается влево и находится теперь между "i" и "o". Теперь, если повернуть энкодер вправо, то должен удалиться символ "o" и все символы справа должна опять сместиться на оди символ влево и получится в результате "Nin F2                                  ", а "|" будет находиться между "i" и "n".

В режиме удаления пользователь также может перемещать курсор влево/вправо зажатием кнопки энкодера и поворотом энкодера. Одиночное нажатие энкодера выводит из режима удаления и внизу экрана, в области меню, "Delete Mode [On]" должно смениться на "Delete Mode [Off]". В режиме удаления долгое нажатие энкодера (более 700мс) также перемещает фокус в облать меню внизу. "Delete Mode" также становится "Delete Mode [Off]".

Если пользователь не ввел имя и нажал "Ok", то нужно показать в области сообщений сообщение "Name is empty". Если введенное имя уже существует, то нужно показать "Name already exists".

Когда пользователь выбирает "Yes" при запросе на сохранение после измерения нужно показывать страницу, на которой пользователь может выбрать между старым именем и заданием нового имени: например "Save as '0002'" и "Save as...". По нажатии на "Save as '0002'" в массив name нужно записать название вида "0002", т.е. как старый вывод имени, где просто форматировался "recordNumber" и сохранить запись с этим именем. При выборе записи "Save as..." нужно показывать новую страницу ввода имени. 

Нужно также реализовать миграцию со старых записей, которые уже есть на устройстве. При миграции нужно в имя (name) позаписывать форматированные recordNumber и сохранить заново все записи. Старый механизм форматирования имени по recordNumber уже не будет использоваться, поэтому нужно позаполнять name.

Серийный API пока не трогай.

Страницу выбора имени («Save as '0002'» / «Save as...») показывай для "Yes", "Overwrite Oldest", "Overwrite Newest", "Sel, rec. to overwrite". При выборе "Yes", "Overwrite Oldest", "Overwrite Newest" нужно показывать страницу редактирования имени без предзаполнения, а в случае "Sel, rec. to overwrite" нужно предзаполнить имя именем той записи, которую выбрал пользователь.

В списках Select record нужно отображать новые имена сразу на 2-х строках более мелким шрифтом, если имя не влазит на 1 строку при обрезании пробелов в хвосте.
